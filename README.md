## Overview of the project:-
Developed an interactive Power BI dashboard to analyze Indian airline stocks, comparing IndiGo and SpiceJet across price trends, trading volume, weekly returns, and volatility. Enabled dynamic insights using KPI cards, slicers, and time-series visuals.This project presents an interactive Power BI dashboard analyzing the stock performance of major Indian airline companies, primarily IndiGo and SpiceJet.

## Key Features:-
- Price trend analysis over time
- Trading volume analysis by date and company
- Weekly percentage change calculation
- Volatility measurement using average daily range
- Interactive slicers for date and company selection

## Tools & Technologies:-
- Power BI
- DAX
- Power Query
- Microsoft Excel / CSV datasets

## Use Case:-
Designed for financial analysis and data-driven comparison of airline stocks to identify trends, volume spikes, and price volatility.
